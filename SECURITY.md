# Security Policy

## Supported Versions
The VeaOS project is currently receiving security updates and fixes. Our team continues to prioritize this version, though an official release is not yet available.
*Note: The VeaOS kernel and its userland are currently under active development and may still contain security vulnerabilities. If you discover a security flaw or bug, please report it immediately to the contacts listed below.*

### Report Format
To help us investigate and patch issues efficiently, your report should be clear and properly detailed. Please include at least the following:
* **Vulnerability Description:** A detailed explanation of the flaw.
* **Exploitation Method / PoC:** Step-by-step instructions or proof-of-concept on how the vulnerability can be triggered.
* **Evidence:** Screenshots or video recordings demonstrating the successful exploit.

*Note: Incomplete or vague reports may delay our response time, as our team will need additional time to manually reproduce and isolate the issue.*

### Bug Bounty Program
We are pleased to announce that VeaOS is opening a Bug Bounty program for anyone who wants to contribute. You are welcome to stress-test our operating system using lightweight malware, custom scripts, or security analysis tools to identify system weaknesses. Please report all findings directly to our contact emails above.
